# Segurança

## Versões com suporte

| Versão | Suporte |
| --- | --- |
| 0.2.x | sim |
| < 0.2 | não |

## Como relatar uma vulnerabilidade

Não abra uma issue pública. Use o relato privado do GitHub: aba **Security**, botão **Report a vulnerability**.

Descreva o problema, a versão do pacote e da Unity, e os passos para reproduzir. A resposta vem em até 7 dias, e a correção sai numa versão nova, com crédito a quem relatou, se a pessoa quiser.

## Escopo

O Paralaxe roda no editor da Unity e dentro do jogo. Ele não acessa a rede, não lê nem grava dados pessoais e não executa código vindo de fora do projeto. As janelas do editor só leem e escrevem assets do próprio projeto.
